# Explanation of the Investor Comps Logic

This document details the inferred logic for how the "Fix & Flip" and "Rental" comps are generated by the external "Comp AI" service. The application's codebase does not contain this logic directly; instead, it interacts with a decoupled microservice.

---

### Architectural Overview

The application utilizes a sophisticated, microservices-based architecture. The core application acts as an orchestrator, while the intensive data analysis is delegated to a separate, standalone "Comp AI" service. This is a robust and scalable approach.

The process is managed by a background job processor (`src/lib/job-processors/analysis-processor.ts`), which calls the external service via a dedicated client (`src/lib/comp-ai-service.ts`).

### Investor Comps Generation Flow

Here is the step-by-step process, from the initial request to the final output:

#### 1. Inputs to the "Comp AI" Service

The main application sends a request to the external service with the following key information:

*   **`imageUrl`**: The public URL of the property's primary image.
*   **`address`**: An object containing the full property address (`street`, `city`, `state`, `zip`).
*   **`userId`**: The ID of the user who submitted the property.
*   **`requestId`**: A unique identifier for tracking and logging the analysis request.

#### 2. The "Comp AI" Service's Internal Process (Inferred)

Once the external service receives the request, it performs a complex series of operations:

*   **Image Analysis:** It uses a computer vision model to analyze the `imageUrl`. This model extracts physical features of the property, such as:
    *   Architectural style (e.g., Colonial, Ranch, Modern)
    *   Exterior condition (e.g., siding, roof, landscaping)
    *   Key characteristics (e.g., number of stories, presence of a garage or pool).

*   **Third-Party Data Integration:** Using the `address`, the service queries multiple external real estate data APIs and sources. These could include:
    *   Multiple Listing Service (MLS) data feeds.
    *   Public records (e.g., county assessor tax data).
    *   APIs from services like Zillow, Redfin, or CoreLogic.

*   **Data Aggregation & Profiling:** The service combines the visual features from the image analysis with the structured data from third-party sources to build a comprehensive profile of the subject property.

*   **Comps Generation:** This is the core of the investor-focused logic:

    *   **For "Fix & Flip" Investors:**
        1.  It identifies recently sold properties in the immediate vicinity with similar characteristics (square footage, age, bed/bath count).
        2.  It specifically searches for properties that were sold in a distressed or un-renovated state and then quickly re-sold after renovation. This is crucial for calculating an accurate **After Repair Value (ARV)**.
        3.  It analyzes market velocity metrics like **Days on Market** and **Sale-to-List Price Ratio** for renovated properties to provide a realistic timeline and budget expectation.

    *   **For "Rental" (Buy-and-Hold) Investors:**
        1.  It identifies currently listed rental properties in the same neighborhood.
        2.  It calculates the average rent for comparable properties to generate an estimated **Market Rent**.
        3.  It pulls local data on vacancy rates, property taxes, and typical HOA fees to calculate key financial metrics like **Cap Rate** and **Rent-to-Price Ratio**.

#### 3. Outputs from the "Comp AI" Service

The service completes its analysis and returns a `CompVisionAnalysis` object. This object is rich with data, including the two key sections for investors:

*   **`flip_comps`**: An object containing all the metrics relevant to a fix-and-flip investment (ARV, price per sqft, etc.).
*   **`rental_comps`**: An object containing all the metrics relevant to a rental investment (market rent, cap rate, etc.).

### Summary

The investor comps are not calculated within this application's main codebase. They are the product of a sophisticated, external "Comp AI" microservice that specializes in real estate data analysis. This service combines computer vision with third-party data aggregation to provide detailed, actionable insights for different types of real estate investors.
